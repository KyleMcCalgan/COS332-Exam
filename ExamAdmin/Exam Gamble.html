ISO/OSI Model — 3–5 Qs

"Layer provides services for layer above" — appears every exam Layer numbers: L4=process-to-process, L5=session, L6=presentation/MIME Layer 5 functions: checkpoints, rollback, synchronisation

ASN.1 / BER — 2–3 Qs

BER = type + length + value — appears every exam Invalid constructors: MESSAGE, ARRAY (valid: SEQUENCE, CHOICE, SET) Syntactic structure defined using a grammar — appears every exam

Application Layer (Email / HTTP / MIME) — 4–6 Qs

SMTP: rcpt to, mail from, data, "." ends body, ehlo→250 MIME: multipart/mixed, multipart/alternative, boundary HTTP: Host: header → virtual hosting; Accept-Charset negotiation Content-Transfer-Encoding: base64 for binary; quoted-printable for mostly-ASCII Header/body separator = blank line (across HTTP, SMTP, RFC822)

Character Encoding — 2–4 Qs

ASCII = 7-bit; extended ASCII characters above 127 may differ between systems UTF-8 self-synchronising: continuation bytes start with 10xxxxxx 4-byte UTF-8 can encode 2²¹ characters (n=21) Accept-Charset with quality values: higher q = more preferred

TCP — 8–10 Qs (heavily tested)

LISTEN = server waiting for SYN TIME-WAIT = waiting for lost traffic before port reuse Persistence timer = window=0, waiting for space; sends probe byte No NAK in TCP — sender retransmission timer expires instead ACK flag not set → acknowledgement field has no meaning No Length field in TCP header (derived from IP total length) netstat = view transport layer connections Port ranges: well-known <1024, registered 1024–49151, dynamic >49151

QUIC — 3–4 Qs (appeared in every exam 2023–2025)

"Quick" = reduces latency in connection establishment / re-establishment Migration: only the CLIENT can initiate in QUICv1/v2 Long header always has: Destination connection ID 0-RTT data can be sent at t0; 1-RTT after handshake completes

UDP — 1–2 Qs

UDP flow control = unrestricted (none) Used for streams tolerant of loss/reorder: audio, video

IPv4 — 8–10 Qs

Private: 10.0.0.0/8 (A), 172.16.0.0–172.31.255.255 (B), 192.168.0.0/16 (C) Longest prefix match — given routing table, find correct next hop Default gateway entry = 0.0.0.0/0 TTL=0 → discard AND send ICMP time exceeded (both — "more than one") Multicast: class D (224–239), delivered to all group members (not TCP) Fragmentation: to fit layer 2 MTU constraints ICMP: reports errors + tests functions (ping = echo request) Bitwise: i AND m = n; i OR (NOT m) = broadcast CIDR block from range: count common bits. 41.32.0.0–41.39.255.255 → /13

Routing Protocols — 3–4 Qs

OSPF = IGP; BGP = only EGP discussed Dijkstra = algorithm (used by OSPF); Bellman-Ford = algorithm (used by RIP) OSPF broadcasts topology; RIP broadcasts routing tables RIP update: new_cost = received_cost + 1

IPv6 — 3–4 Qs

128 bits, 8 groups of 4 hex, routing prefix = first 64 bits fe80::/10 = link-local; fd00::/8 = unique local (private) IPv4-mapped: ::ffff:0/96 fd prefix structure: 8-bit prefix + 40-bit random + 16-bit subnet + 64-bit interface

Layer 2 — 3–5 Qs

IEEE 802.3=Ethernet, 802.5=Token ring, 802.11=Wireless LAN HDLC transparency = bit stuffing (insert 0 after five 1s) FF:FF:FF:FF:FF:FF = broadcast; promiscuous mode = accepts all frames OUI = first 3 bytes of MAC = manufacturer Layer 2 does NOT do routing — that is layer 3

Physical / General — 2–3 Qs

GEO round-trip ≈ 0.24s; LEO = lower latency, smaller transmitter needed Manchester encoding = self-synchronising SAT3 = undersea cable (not a satellite) Cold War → ARPANET design; RICA = SA wiretapping act
2 UTF-8 Encoding & Decoding
Certain 10 marks
  • 🎯
    Parts a–c (3 marks): Convert 3 Unicode codepoints to UTF-8 hex. Expect one 2-byte, one 3-byte, one 4-byte character.
  • 🎯
    Parts d–h (5 marks): Given an invalid byte stream — find valid chars, identify invalid bytes, re-synchronise.
  • 🎯
    Part i (2 marks): Creative question — 2025 was the SA flag emoji (ZA = two 4-byte Regional Indicator Symbols). Could be similar in 2026.
  • 💡
    Lecturer's shortcut hint: Determine byte count from the magnitude of U+xxxx — no need to fully encode. U+0000–007F=1 byte, U+0080–07FF=2 bytes, U+0800–FFFF=3 bytes, U+10000–10FFFF=4 bytes.
UTF-8 encoding table: U+0000–007F → 0xxxxxxx (1 byte) U+0080–07FF → 110xxxxx 10xxxxxx (2 bytes, 11 data bits) U+0800–FFFF → 1110xxxx 10xxxxxx 10xxxxxx (3 bytes, 16 data bits) U+10000–10FFFF → 11110xxx 10xxxxxx 10xxxxxx 10xxxxxx (4 bytes, 21 data bits) Self-sync rule: start byte ≠ 10xxxxxx; continuation byte = 10xxxxxx (80–BF) Invalid: a lone continuation byte, or a start byte not followed by enough continuation bytes
3 Subnetting & Supernetting
Certain 10 marks
  • 🎯
    Given a CIDR block with a real-world context (ISP/org), subnet it into min X subnets with min Y hosts each.
  • 🎯
    Find network addresses of specific subnets (1st, Nth) in CIDR notation.
  • 🎯
    Supernet the last K subnets — find supernet network address + broadcast.
  • 💡
    The lecturer's hint: you may be given a router and asked for a routing table entry for a specific subnet — destination = CIDR network address, next hop = IP of next router (or interface name if directly connected).
Steps: 1. Host bits h: 2^h - 2 ≥ required hosts → find minimum h 2. Subnet bits s: remaining bits in the address (32 - original_prefix - h) 3. New prefix = original_prefix + s 4. Subnets created = 2^s 5. Subnet N network address = base_address + N × (2^h) 6. Broadcast = network_address + 2^h - 1 Supernetting: - Merge 2^k aligned subnets → decrease prefix by k - Supernet must be naturally aligned (network address divisible by supernet size)
4 TCP Analysis
Very High 10 marks

Format A — Wireshark trace (2025 style)

Which line completes the opening handshake? What does ACK=1 in line 2 imply about line 1? (phantom byte in SYN) Does an ACK segment include a phantom byte? (No — ACK itself consumes nothing) How many bytes consumed when server first ACKs? (all 365 = Ack 366) Why was line 10 necessary? (retransmit of lost FIN)

Format B — Header field values (2024 style)

Sequence number = next byte to send from this side Acknowledgement number = next byte expected from remote Length = min(data_to_send, their_window) Window advertisement = your remaining receive buffer space SYN flag = 0 once connection is established
  • 💡
    Lecturer's explicit hint: The ACK flag acknowledges the phantom byte during the handshake (Ack = SYN seq + 1) and acknowledges real data after. The mechanism is identical — you can tell which it is by whether Ack = remote's initial seq + 1.
5 DNS Zone Files
Very High 10 marks
  • 🎯
    Parts a–f: Write resource records for specific zone files given facts about a domain (NS, A, AAAA, MX, CNAME, TXT, PTR).
  • 🎯
    Parts g–j: Perform recursive name resolutions OR insert records for MX primary/backup, CNAME alias, AAAA, TXT.
Record types to know: NS → delegates zone to a name server example: za NS za1.dnsnode.net. A → IPv4 address example: ftp A 197.221.2.30 AAAA → IPv6 address example: ftp AAAA 2606:4700:20::ec5 MX → mail exchange (lower priority number = higher preference) example: @ MX 10 ASPMX.L.GOOGLE.COM. @ MX 20 ALT1.ASPMX.L.GOOGLE.COM. CNAME → alias (canonical name) example: zz CNAME example.com. SOA → start of authority (primary NS declaration) example: @ SOA ns1.host-h-net. ... PTR → reverse DNS: 5.98.215.137.in-addr.arpa → 137.215.98.5 TXT → arbitrary text: @ TXT "x=1" Zone file relative names: - In xx.co.za zone, "ftp" means ftp.xx.co.za - Trailing dot makes name absolute: "ns1.host-h-net." is FQDN - "@" refers to the zone apex (xx.co.za itself)
6 Bellman-Ford Routing Tables
Very High 5 marks
  • 🎯
    Given routing tables at C, D, E at t0. At t1 node C sends its table to D. At t2 node E sends its table to D. Answer: what is D's entry for destinations A, B, F after each exchange?
Algorithm when D receives table from C: For each destination X in C's table: proposed_cost = D's_current_cost_to_C + C's_cost_to_X if proposed_cost < D's_current_cost_to_X: D's entry for X = (X, proposed_cost, next_hop=C) else: D's entry for X unchanged Note: D's cost to C is found in D's own routing table. Entry format: destination | cost | next_hop Example: A | 10 | C
7 Dijkstra's Algorithm
High 5 marks
  • 🎯
    Partially completed table with columns: Step, S (settled set), W (working set), X (node added this step), cost and predecessor columns for each node.
  • 🎯
    Fill in the blanks marked (a), (b), (c) etc. Usually 5 blanks = 5 marks.
Algorithm from source A: 1. S = {A}, cost[A] = 0, cost[others] = ∞ 2. Each step: X = lowest-cost node NOT in S 3. Add X to S 4. For each neighbour N of X not in S: new_cost = cost[X] + edge(X, N) if new_cost < cost[N]: cost[N] = new_cost prior[N] = X 5. Repeat until all nodes in S Common blank types: - Cost of a node after relaxation through newly added X - Predecessor of a node - Which node X is added at each step - The contents of S or W
8 Wildcard Question
Medium ~5 marks

This slot varies — most likely candidates in order of probability:

Option A — TCP Timers (ST2 2025 + ST2 2026)

Retransmission → segment is retransmitted Acknowledgement → cumulative ACK is sent Persistence → probe byte sent (window was 0) Keepalive → keepalive probe sent to check connection still alive Quiet timer → prevents use of old sequence numbers after reconnect

Option B — SMTP / FTP / POP3 Commands (2024 Q2)

POP3: RETR 5 (download message 5) SMTP: RCPT TO: d@xx.co.za SMTP: DATA (start of message body) HTTP: GET / HTTP/1.1 FTP: PASV (passive mode)

Option C — Routing Table Reading (2022 / 2026 ST2)

Given actual router output + tracert, determine topology and paths Default gateway config determines which path is taken nslookup: set type=AAAA for IPv6; PTR format = reversed address + .in-addr.arpa

The lecturer did not merely mention UTF-8 — he worked through a specific technique in full: determining byte count from the magnitude of a U+xxxx code point without performing the full encoding. He chose U+1003, U+AA80, and U+2C03 as examples and solved all three step by step. A lecturer does not spend that kind of space in a pre-exam message on a technique unless it appears on the paper. This is the strongest individual signal in either message.

"Would you be able to do this without fully encoding each of the three Unicode characters?"
Direct lecturer signal

He called it "perhaps a trick question" — which is an explicit warning that this exact angle will appear. When a lecturer flags something as a potential trick, they are pointing at the question, not just the topic.

"Suppose I ask you how one would know whether a given instance of the ACK flag acknowledges a SYN or acknowledges receipt of some data."

"Suppose I ask you to provide a routing table entry at some router for the network X … the destination will then be the network address … the next hop could literally be the IP address of the next router."

The dialogue he provided is a map of what he considers examinable within this concept cluster.
